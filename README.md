# AutoSMS - Premium Bulk Messenger

안드로이드 휴대폰을 사용하여 엑셀 주소록 기반으로 단체 문자를 발송하는 프로그램입니다. 구글 메시지(Google Messages) 앱을 기본으로 사용합니다.

## 🚀 시작하기

1.  **휴대폰 설정**:
    -   휴대폰 설정 > 휴대전화 정보 > 소프트웨어 정보 > **빌드 번호**를 여러 번 클릭하여 '개발자 모드'를 활성화합니다.
    -   설정 > 개발자 옵션 > **USB 디버깅**을 켭니다.
    -   휴대폰을 PC와 USB 케이블로 연결합니다.
2.  **프로그램 실행**:
    -   `run.bat` 파일을 실행합니다. (필요한 ADB 파일은 자동으로 다운로드됩니다.)
3.  **사용 방법**:
    -   **엑셀 불러오기**: 준비된 엑셀 파일을 선택합니다. (샘플 파일은 `samples/sample_contacts.xlsx`에 있습니다.)
    -   **그룹 선택**: 발송하려는 그룹을 체크합니다.
    -   **메시지 작성**: 엑셀에 개별 메시지가 없는 경우 발송될 공통 메시지를 입력합니다.
    -   **발송 시작**: '발송 시작' 버튼을 누릅니다.

## 📊 엑셀 파일 형식

엑셀 파일은 반드시 다음 컬럼을 포함해야 하며, 순서를 지켜주세요:
1.  **이름**: 학생 또는 수신인의 성함
2.  **그룹**: 연락처가 속한 그룹 (예: 친구, 회사, VIP)
3.  **연락처**: 수신인 번호 (01012345678 형식)
4.  **메시지**: 해당 사람에게만 보낼 개별 메시지 (비어있을 경우 UI의 공통 메시지 사용)

## ⚠️ 주의사항

-   **스팸 주의**: 단시간에 너무 많은 문자를 보내면 통신사에서 차단될 수 있습니다. 기본 설정된 지연 시간(5초 이상)을 유지하는 것을 권장합니다.
-   **구글 메시지**: 이 프로그램은 **구글 메시지** 앱을 기본으로 사용하도록 최적화되어 있습니다.
-   **전송 버튼**: 프로그램이 휴대폰의 문자 앱을 실행하면, 자동으로 '전송' 버튼을 누르기 위해 키 이벤트를 보냅니다. 휴대폰 화면이 켜져 있고 잠금이 해제되어 있어야 합니다.
