# 🚀 Auto SMS Premium - Pro Edition

Auto SMS Premium은 대량 문자 발송을 위한 올인원 솔루션입니다. **SOLAPI** 연동을 통한 대량 발송과 **ADB(Android Debug Bridge)**를 이용한 스마트폰 무료 발송 기능을 모두 지원합니다.

## ✨ 주요 기능

-   **Dual Sending Mode**:
    -   **SOLAPI**: API 연동을 통한 빠르고 안정적인 대량 발송 서비스 (유료 서비스 연동 필요)
    -   **ADB**: 스마트폰을 직접 제어하여 이동통신사 무료 문자/무제한 요금제를 활용한 발송
-   **스마트 주소록 매니저**:
    -   엑셀(XLSX, CSV) 파일을 통한 대량 연락처 업로드 및 내보내기 지원
    -   그룹 필터링을 통한 선택적 발송
-   **개별 맞춤 메시지 (Memo Sending)**:
    -   엑셀의 '메모' 컬럼 내용을 각 수신인별로 다르게 발송하는 기능 지원
-   **발송 히스토리**:
    -   발송된 내역을 실시간으로 확인하고 로그를 관리
-   **Premium UI/UX**:
    -   CustomTkinter를 사용한 모던한 다크 테마 GUI 환경

## 🛠️ 시작하기

### 1. 기본 설정 (공통)
1.  Python 3.8 이상이 설치되어 있어야 합니다.
2.  필요한 라이브러리를 설치합니다:
    ```bash
    pip install -r requirements.txt
    ```
3.  `run.bat` 파일을 실행하여 프로그램을 시작합니다.

### 2. SOLAPI 발송 모드 설정
1.  [SOLAPI](https://solapi.com) 회원가입 및 API Key를 발급받습니다.
2.  프로그램 내 '설정' 탭에서 API Key, Secret Key, 발신 번호를 등록합니다.
3.  '잔액 확인'을 통해 연동 여부를 테스트합니다.

### 3. ADB 스마트폰 발송 모드 설정
1.  **휴대폰 설정**:
    -   설정 > 휴대전화 정보 > 소프트웨어 정보 > **빌드 번호**를 여러 번 클릭하여 '개발자 모드' 활성화
    -   설정 > 개발자 옵션 > **USB 디버깅** 활성화
2.  휴대폰을 PC와 USB로 연결하고 권한 승인 팝업을 확인합니다.
3.  프로그램 설정에서 '기기 연결 확인'을 클릭합니다.
4.  (옵션) 전송 버튼의 화면 좌표를 입력하면 완전 자동 발송이 가능합니다.

## 📊 데이터 준비 (Excel)

엑셀 파일은 다음 헤더 중 하나를 포함하면 자동으로 인식합니다:
-   **이름**: 수신인 성함
-   **전화번호**: 010-XXXX-XXXX 형식 (하이픈 유무 무관)
-   **그룹**: 필터링을 위한 그룹명
-   **메모**: 개별 발송 시 사용될 메시지 내용

## ⚠️ 주의사항

-   **스팸 방지**: 단시간 대량 발송 시 통신사 스팸 정책에 의해 차단될 수 있습니다. ADB 모드 사용 시 적절한 대기 시간을 설정하세요.
-   **기기 보안**: ADB 발송 시 휴대폰 화면 잠금이 해제되어 있어야 원활한 제어가 가능합니다.
